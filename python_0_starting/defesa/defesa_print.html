ex00: First Python Script (Hello.py)

  • Listas: Mutáveis e ordenadas. Acesso por índice (ft_list[1] = "World!").
  • Tuplas: Imutáveis e ordenadas. Reatribuídas como nova tupla (ft_tuple = ("Hello", "Brazil!")).

ex01: First Use of Package (format_ft_time.py)

P: O que representa o Timestamp Unix?
O número total de segundos decorridos desde 1º de janeiro de 1970 (00:00:00 UTC), conhecido como Epoch Unix.
P: Como é feita a formatação em notação científica no Python?
Usando o especificador de formato :.2e dentro de f-strings (ex: f"{timestamp:.2e}" gera 1.71e+09).

ex02: First Function Python (find_ft_type.py)

P: Qual a diferença entre `type()` e `isinstance()`?
type() verifica a correspondência exata de classe da instância. isinstance() verifica se o objeto pertence àquela classe ou a qualquer subclasse descendente.

ex03: NULL Not Found (NULL_not_found.py)

P: Por que `float("nan") == float("nan")` retorna False?
Conforme o padrão IEEE 754 de ponto flutuante, NaN (Not a Number) é definido para não ser igual a nenhum valor, inclusive a si mesmo. A detecção correta exige a função math.isnan().
P: Como diferenciar `False` de `0`?
Em Python, False == 0 avalia como True porque bool herda de int. Devemos validar o tipo com type(obj) is bool versus type(obj) is int.

ex08: Loading (Loading.py)

P: Como o caractere `\r` permite atualizar a barra de progresso no terminal?
O caractere de retorno de carro \r move o cursor para o início da linha atual no terminal, permitindo sobrescrever o texto da barra de progresso dinamicamente.

É a especificação moderna (PEP 517/518) para declarar os requisitos do sistema de build e metadados da biblioteca para distribuição no PyPI/pip.
