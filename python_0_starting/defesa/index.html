Data Structures & Mutability

Modify elements inside standard Python data structures: List, Tuple, Set, and Dict.

  • List: Mutable, ordered. Modified via index (ft_list[1] = "World!").
  • Tuple: Immutable. Cannot be modified in place; reassigned as a new tuple.
  • Set: Unordered, unique items. Modified with .remove() and .add().
  • Dict: Key-value pairs. Modified via key access (ft_dict["Hello"] = "42...").

Q&A for Defense

Q: Why can't we modify a Tuple in place?

"Tuples are immutable collections. Once instantiated, their memory footprint and pointers cannot change. This makes them hashable."

ex03: NULL Not Found

File: NULL_not_found.py

COMPLETE

Falsy & Null-like Values

Distinguish between different representations of "null" in Python: None, NaN, 0, "", and False.

  • None: Checked via obj is None.
  • NaN: IEEE 754 float where nan != nan. Checked via math.isnan(obj).
  • False vs 0: Checked by validating type(obj) is bool versus type(obj) is int.

Q&A for Defense

Q: Why does `float("nan") == float("nan")` return False?

"Per the IEEE 754 floating-point standard, NaN (Not a Number) is defined to not be equal to any value, including itself. `math.isnan()` must be used."
